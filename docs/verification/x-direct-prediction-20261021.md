用户要求 X 为主、第三方兜底，中文文字/语音不变；重点是提前预测，不是完成公告。新增 Edge MV3 扩展、本机 Native Messaging 桥接、直连新鲜度检查和透明规则分级。默认只提醒低把握线索与明确预告，完成作为结果；同一 Day N 事件后来完成时结束旧预警。
